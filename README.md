# 국내 주식 수급 분석 — Render Web Service 실험판

## 확인된 범위
- Python 문법 검사 및 패키지 ZIP 무결성 검사 완료.
- 수집 로직은 비공식 pykrx 사용. 실제 KRX 접속 및 확정 수급 데이터 성공 여부는 **검증하지 못함**.
- 종목 20개 기본 조회, 전체 시장 TOP 10 아님.
- 실행 버튼은 공개되어 있으므로 실서비스에는 인증/접근 제한이 필요함. 10분 재실행 제한을 적용함.
- Render 무료 서비스는 재시작 시 분석 결과가 사라질 수 있음.
- 자동 일정 실행은 미구현. Render의 유료/외부 스케줄러 별도 필요.
- 주문 기능 없음.

## 배포
1. 저장소 루트에 압축 해제한 파일을 업로드.
2. Render > New > Blueprint에서 render.yaml을 선택하여 Python Web Service 생성.
3. 기존 Static Site는 Python 실행을 지원하지 않음.
4. 서비스에서 분석 버튼을 눌러 오류 진단 확인.

## 한계
pykrx는 비공식 수집기이며 소스 변경/차단에 의해 작동하지 않을 수 있습니다. 외부 네트워크에서 성공했다고 주장하지 않습니다.
